1. Aceptación y alcance

Estos términos describen el uso de Radio México de Siempre, una aplicación Android de FA APP STUDIO. Al instalarla o utilizarla, aceptas estos términos. Si no estás de acuerdo, deja de utilizar la aplicación y desinstálala.

2. Servicio

La aplicación permite escuchar emisoras de radio por internet. Es gratuita, puede mostrar publicidad y no requiere crear una cuenta ni realizar compras dentro de la aplicación. Para reproducir audio se necesita una conexión a internet.

3. Emisoras y disponibilidad

Las transmisiones proceden de servicios de terceros operados por las emisoras. Su programación, contenido, disponibilidad, calidad y condiciones pueden cambiar o dejar de estar accesibles. FA APP STUDIO no controla esas transmisiones y no puede garantizar que una emisora esté disponible en todo momento o en todos los territorios.

4. Uso de la aplicación

Utiliza la aplicación de forma lícita y sin interferir con su funcionamiento, intentar acceder a sistemas de forma no autorizada ni utilizarla para vulnerar derechos de terceros. El usuario es responsable de contar con un dispositivo compatible y una conexión adecuada; el uso de datos móviles puede generar cargos de su operador.

5. Publicidad y servicios de terceros

La aplicación puede mostrar anuncios proporcionados por Google. También depende de servicios externos para entregar las transmisiones de radio. El uso de esos servicios puede estar sujeto a sus propios términos y políticas. Consulta nuestra política de privacidad para conocer cómo se tratan los datos.

6. Cambios y contacto

Podemos actualizar la aplicación o estos términos para reflejar cambios del servicio o requisitos aplicables. La versión vigente y su fecha se publicarán en esta página. Para consultas sobre la aplicación o estos términos, escribe a faappstudio@gmail.com.
